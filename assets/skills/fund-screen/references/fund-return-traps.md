# 基金收益字段口径陷阱（指针）

**正文只有一份**：`../../_shared/references/fund-return-traps.md`
（即插件内 `assets/skills/_shared/references/fund-return-traps.md`）。本文件不再保存正文，
只留标题索引，避免「改一漏四」。

1. 同花顺「近N年收益率」年化与累计共用同一列名 —— 唯一判据 `indicators_params.是否年化`；取不到就按量级自检。
2. Wind「近N年年化」≈ 几何年化的 1.94–2.13 倍且倍数不固定（本插件现不接 Wind，保留备用）。
3. 「规模」是全份额合并口径，与单一份额可差一档；门槛判定须两种口径并列。
4. 通用原则：厂商字段名 ≠ 定义；会改变入选集的字段，要么取到口径文档，要么自算复核。

要细节（实测后果、必须怎么做）请读正文。
