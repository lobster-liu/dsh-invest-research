# 基金销售费用规则（2026）与净成本口径

**唯一副本。** 引用方：`fund-profile`、`fund-research/roles/fund-profile.md`、`fund-screen`、
`fund-watch`、`pick-funds`。改这里 = 改全部；不要再复制出第二份。

这份文件只回答一个问题：**这只基金、这个渠道、这个时点，持有人实际付出多少销售费用？**
费率字段本身不是答案（同一只基金的 A 类与 C 类、直销与代销，净成本可能差一个数量级）。

---

## 0. 证据分级：层级三档 × 来源类型五类

两个维度分开写，不许混：**层级**回答「这条结论能不能出点估计」，**来源类型**回答「这条结论是谁说的」。
**层级固定三档，来源类型可增列**——新增来源类型不等于新增层级，别把下面第二张表的行读成「第四档」。

| 层级 | 生效日 | 含义 | 能不能写进代码/报告 |
|---|---|---|---|
| **原文级** | 2026-01-01 | 法规公报原文可核（§1） | 可以，按条文号引用 |
| **转述级** | 2027-01-01 | 无公开原文的执行层规则，**逐条强度不同**（见 §2） | 可以，但须标「转述级」+ 该条**实际来源类型**，写清无文号 |
| **推论** | 至迟 2026-12-31 | 由原文 + 时间表推出来的时序 | 只能写成「推论」 |

| 来源类型 | 层级归属 | 能证明什么 |
|---|---|---|
| **法规公报** | 原文级 | 规则这样要求；可按条文号引用 |
| **两家独立媒体** | 转述级 | 两条独立转述一致（每日经济新闻 2026-01-15、中国基金报 2026-01-11）；仍无文号 |
| **单家媒体** | 转述级（弱） | 仅一家可见；**不得写成多源一致** |
| **基金公告（单例）** | 转述级 | 该管理人已按此执行；**不证明规则这样要求，不推广为通例** |
| **真实合同落地** | 转述级（文本可逐字引用；原件/编号未取得） | 合同/公告已写明，可逐字引用；**不提升层级**，也不证明规则本身 |

同一份公告可同时挂「基金公告（单例）」与「真实合同落地」两个角色，但**来源计数只算一次**——
写「两个来源印证」属于重复计数。

上游称另有第三家同题报道，原件未核到，不引。

**禁止**：给配套《通知》补文号、发文日期、条文号，或把它写成「证监会公告」。它对持有人是
**真实约束**（合同里已经在执行），但它不是公开文件——这一点必须在报告里说清楚，因为读者
无法自己核到原文。

## 1. 规范层：〔2025〕22号 里与「净成本」直接相关的条文

证监会公告〔2025〕22号《公开募集证券投资基金销售费用管理规定》，2025-12-31 发布，2026-01-01 施行；
国务院公报 2026 年第 9 号 `https://www.gov.cn/gongbao/2026/issue_12646/202603/content_7064116.html`（原文可核）。

| 条 | 内容（原文级） | 对结论的影响 |
|---|---|---|
| 第七条（第三段） | 基金管理人销售其管理的基金，不得收取认（申）购费、销售服务费 | 第七条自 **2026-01-01** 起设定**禁收义务**；配套《通知》给过渡，**直销腿实际停止收取日 = 2027-01-01**。所以 2026 年直销腿必须按合同**实收**计，**禁止按 0 建模**。代销腿的认（申）购费按第八条上限继续收，不受本条约束。合同例证：路博迈中国动力 2026-07-06（单例）把 A 类改为「直销申购不收、其他销售机构 0.80%」——**该基金是提前执行，不是效力日**，别把它的生效日当成规则生效日 |
| 第八条 | 认（申）购费上限：主动偏股型 0.8%、其他混合型 0.5%、指数型与债券型 0.3% | 超过上限的报价一律视为口径错误（含「费率高＝更好」这类反常识表述） |
| 第九条 | 后端收费模式下，持有超过一年**可以**免收 | 是**授权**不是义务：写「满一年自动免收」是规则错误，只能写「合同约定可免收」 |
| 第十条 | 赎回费按持有期限设置，且全额计入基金财产 | 赎回费不是管理人的收入，也不进 A/C 净成本对比；但它是持有人真实支出，单列 |
| 第十一条 | 销售服务费上限：股混 ≤0.4%/年、指数与债券 ≤0.2%/年、货基 ≤0.15%/年；**不收取认（申）购费的份额可以收取销售服务费**；除货基及证监会认可的其他基金外，持续持有超过一年的份额不得继续收取销售服务费 | C 类「免申购费」不是免费：成本在销售服务费里，按持有期线性累积 |
| 第十五条 | 第二段：基金管理人不得为实行**差异费率**通过在特定基金销售机构设置**专属份额**等形式，不公平对待同一基金的不同投资者 | 规范层对「差异化份额」的禁止只到这里：**不公平对待**被禁，统一费率本身不被要求。「2027-01-01 前完成份额合并或同费率整改」的**时限**仍来自《通知》，属转述级 |
| 第十六条 | 不得通过在特定基金销售机构设置**专属基金产品**等形式，实施歧视性、排他性、绑定性销售安排 | 遇到「某渠道专属份额」先按本条判合规，再谈费率比较；专属份额的 A/C 净成本不可跨渠道直接比 |
| 第二十条（三） | 「**未经公告擅自变更**向投资者的收费项目或收费标准，或通过**先收后返**、财务处理、送红包等各种方式变相降低收费标准」 | 限定语是「未经公告擅自」：**有公告/合同依据的先收后返不违禁**（《通知》要求的先收后返正是这种）；私下返还、账外返还才是违规，不能当成本依据。引文别截断——只写「禁止先收后返」会把《通知》要求的机制读成违禁 |
| 第二十九条 | 2026-01-01 施行；已发售基金 12 个月内完成调整 | 2026 年内同一只基金可能处在「新旧费率并存」的过渡状态 |

> **条 ↔ 段**：公报按自然段排版，**没有「×款」编号**。散文引用写「第七条（第三段）」，代码注释只写
> 「第七条」（`fund_cost.py` 里就只有第七/八/十一/二十九条，无需改动）。销售子公司销售母公司基金
> 参照第七条适用——**「参照」这层是媒体说法（中国基金报），不是公报原文**，写结论时单独标转述级。

## 2. 执行层（转述级）：2027-01-01 起

《通知》下发至机构，**无文号、无发文日期、无公开全文**。以下 7 条**来源不一致，必须逐条标**
（括号内是 §0 的**来源类型**，不是层级）——写成「七条均有双源一致」就是越级：

1. **认（申）购费**〔**两家独立媒体**〕：对收取认（申）购费的基金份额，基金管理人自 **2027-01-01** 起
   **不得继续收取**。没有返还机制——不是「先收后退」，是**不再收**。**管辖对象与第七条相同：直销腿**
   （管理人或其销售子公司），管的是它的过渡终点；**代销腿按第八条上限继续收取，不因 2027 停收**
   （`test_fund_cost.py` 的 F1b 正是这个边界：代销 2027 年仍可收 0.80%）。
2. **销售服务费**〔**两家独立媒体**〕：可以继续收取，但应当在投资者**赎回或基金合同终止**时，把 **2027-01-01 之后收取的部分全额返还**。
   对**适用返还的部分**——① **直销腿**：**2027-01-01 起计提**的部分，不问持有期；② **代销腿**：**持有 >1 年**
   且 **2027-01-01 起计提**的部分——**净成本 = 0，现金流 ≠ 0**。
   **不返还的两类**（净成本 = 实收）：**2027-01-01 前计提的存量**（不分渠道、不分持有期）、以及**代销腿
   持有 ≤1 年的部分**（合同分支，见第 3 条，与 G1/F1b 一致）。别把「净成本 = 0」套到全部 C 类上。
3. **存量不返还**〔**基金公告（单例）**〕：2027-01-01 前已计提的销售服务费不返还。公告全文可公开核
   （好买基金转载页 `https://www.howbuy.com/fund/info/dtl/0202365354850.htm`；公告 **PDF 副本（好买托管）**
   `https://static.howbuy.com/gkxx/ggfile//2026/2026-7/2026-07-06/5354849.pdf`——**不是管理人官网原件页，
   该页也无公告编号**），逐字为「**但在2027年1月1日之前计提的销售服务费将不返还给投资者，而是确认为应
   支付的销售服务费**」。后半句不能省：「不返还」不等于「费用消失」，钱转为**应支付**的销售服务费，
   现金流照样发生。正文自述原发渠道为管理人官网 `www.nbchina.com`、证监会基金电子披露网站
   `http://eid.csrc.gov.cn/fund`、《上海证券报》——**原件页与公告编号未取得**，故按【基金公告（单例）】
   ＋【真实合同落地】双重角色使用（**来源计数只算一次**），不写成「公告编号可核」。两家媒体正文均无
   「不返还」字样。引用时写清现名与改名关系（施罗德中国动力 → 路博迈中国动力，A/C 代码 020236/020237
   未变，2026-07-06 合同生效）。

   **限定两层，缺一即过度推广**：
   - **份额层**：这句只覆盖「**由施罗德中国动力转换而来的 C 类份额**」，不覆盖该基金全部 C 类，更不覆盖其他基金。
   - **渠道层**：公告的代销分支按**持有期**分两支 —— **持有 ≤1 年**：所计提的销售服务费**全部确认为应支付
     （不返还）**，2027 前、2027 后都不返还；**持有 >1 年**：**2027-01-01 起继续计提的部分返还**，此前计提的
     不返还。所以准确说法是：**「存量不返还」在代销腿上没有持有期切换**（2027-01-01 前计提的，无论持有
     ≤1 年还是 >1 年都不返还）；**按持有期切换的是 2027-01-01 起继续计提的部分**。别写成「代销全期都不
     返还」——那和 >1 年一支直接冲突。
   - **判定时点**：公告用的是「持续持有期限（即 365 天）」。我们按**赎回时的连续持有期**理解——这是**解释，
     不是原文**，报告里必须写明判定时点，否则同一笔费用会因「哪天算持有满一年」而改号。
4. **持续持有超一年**〔**两家独立媒体**〕：**两层写，别混**——
   - 规范层（**第十一条，2026-01-01 起**）：除货基及证监会认可的其他基金外，持续持有超过一年的份额
     **不得继续收取**销售服务费。
   - 执行层（**《通知》，2027-01-01 起**）：每经原句「自 2027 年起，对于持续持有期限超过一年的非货币市场
     基金份额，基金销售机构不得继续收取销售服务费」，落地形态是先收后返。
   只写 2027 会把 2026 年误读成「仍可对持有超一年的份额收费」——规范层 2026 年就已经禁了。
5. **差异化份额整改**〔**两家独立媒体**；规范层依据已核〕：2027-01-01 前完成份额合并或同费率整改
   ——**这个时限只来自《通知》，仍是转述级**。规范层的禁止只到「不公平对待」：公报**第十五条**第二段
   「基金管理人不得为实行差异费率通过在特定基金销售机构设置专属份额等形式，不公平对待同一基金的不同
   投资者」，**第十六条**另禁「在特定基金销售机构设置专属基金产品」式的歧视性、排他性、绑定性安排。
   条款号**可作引用依据**（此前「媒体转引·待核」的判断已撤销）。
6. **「已发售基金」的范围**〔**单家媒体**：仅中国基金报 2026-01-11〕：含 2025-12-31（含）前成立、以及已发布
   发售公告的基金。
7. **调整费率无需召开持有人大会**〔**单家媒体**：仅中国基金报 2026-01-11；合同已作授权约定〕。

引用时写「配套《通知》（转述级，无文号）」。三条红线：

- **单家媒体不得写成多源一致**：第 6/7 条只在中国基金报可见，写「多家媒体报道」即为越级。
- **第 3 条是单只基金公告的合同级落地，不是媒体转引**：可以写「某只基金已在公告中执行」，不能推广成
  「全部基金已如此执行」——把单例当通例，是这份文件最容易犯的错。
- **条款号以公报正文为准**：公报按自然段排版、无「×款」编号（散文写「第七条（第三段）」，代码只写「第七条」）；
  公报里查不到的条/款序号才标「媒体转引·待核」，且不得进入代码注释、报告正文或测试断言。

## 3. 三维度登记：不登记就等于没算

任何一个费用数字，落盘前必须能回答这三个问题，缺一即为**口径不明**：

1. **渠道**：`直销`（管理人及其销售子公司）还是 `代销`。第七条与 2027 过渡只作用于直销腿；
   代销腿的认（申）购费受第八条上限约束，不因 2027 停收。
2. **申购时点**：2026-01-01 前 / 2026 年 / 2027-01-01 及以后。跨 2027-01-01 的持有期**必须分段**。
3. **口径**：`实收`（合同费率 × 金额）还是 `应退 / 净成本`。2027 年后的销售服务费**两列都要有**。

## 4. 净成本公式

```
净成本(持有期 T) = 认（申）购费实收 + Σ 销售服务费实收 − 应退销售服务费
                 （管理费、托管费已从净值中扣除，不重复加；只作并列比较项）
```

- **2027 年后的直销 C 类**：`认（申）购费实收 = 0`；`销售服务费实收 = 应退`（仅限 2027-01-01 起计提部分），
  **净成本 = 0**，但**现金流不为 0**——把返还额从历史现金流里抹掉，等于篡改了投资者真实经历的扣款。
- **代销 C 类不适用上一条**：认（申）购费按第八条上限**继续收**（F1b 即 0.80% 边界，不因 2027 停收）；
  销售服务费**持有 ≤1 年不返还**（净成本 = 实收）、**>1 年才返还 2027 后计提部分**。
- 2027-01-01 **前计提的存量不返还**（不分渠道、不分持有期），净成本 = 实收（G1）。
- 直销腿 2026 年内仍然可能收费（第七条 2026-01-01 起施行，但存量合同 12 个月内调整）；
  以**实际公告/合同**为准，不以「应该为 0」倒推。
- 费率版本键：**(基金代码, 费率变更生效日)**。同一只基金在 2026 年内可能有两个版本，
  拿「最新费率」去算 2025 年的持有成本是错的。

## 5. 校验与降级（实现见 `fund-research/tools/fund_cost.py`）

| 代号 | 情形 | 处置 |
|---|---|---|
| E1 | 直销 + 2027-01-01 及以后 + 认（申）购费实收 > 0 | 抛 `CostCaliberError`：2027 起不得收取 |
| E2 | 2027-01-01 及以后，销售服务费只给实收、不给应退 | 抛错：两列必须同时给 |
| E3 | 应退 ≠ 实收（2027 后收取部分） | 抛错：执行层要求全额返还 |
| E4 | 持有期跨 2027-01-01 却未分段 | 抛错：先分段再算 |
| E5 | 把返还额从历史现金流中抹掉 | 抛错：净成本 0 ≠ 无现金流 |
| E6 | 后端口径写成「满一年自动免收」 | 规则错误：第九条是「可以免收」 |
| E7 | 费率/渠道/生效日缺一，或规则未核到 | 输出「**费用不可精确复算**」，不得估算 |

## 6. 报告里怎么写

- 每个费用数字带四元组：`【来源|日期|口径|类型】`，类型写 `披露` / `计算` / `转述`。
- 费率表必须写清**份额类别 + 渠道 + 生效日**：`管理费 1.20% / 托管费 0.20% / 销售服务费 0.40%（C 类，代销，2026-08-01 起）`。
- 涉及 A/C 选择、持有期盈亏平衡、2027 前后成本比较时，**必须引用本文件**并给出分段结果。
- 只引用 `hexin-fund.get_fund_profile` 或 `wind-fund.get_fund_info` 的「费率」字段时，
  必须同时声明：**该字段不含渠道与口径**，因此不能直接当作持有人净成本。

## 7. 已知边界：工具现在表达不了的情形

`fund_cost.py` 的 `validate_fee_leg(channel, trade_date, fee_kind, received, refundable)` 只有四个输入，
**没有持有期**。它在 2027-01-01 及以后对销售服务费**不分渠道**都要求「应退 = 实收」（E3）。而真实合同里
（§2 第 3 条代销分支）：**代销腿持有 ≤1 年的部分为「全部确认为应支付」，不返还**——用它去算会得到 E3
误判。

- 现在能表达的：**直销腿**全部分支、代销腿的认（申）购费（第八条上限内继续收）。
- 现在表达不了的：**代销腿 + 2027 后 + 持有 ≤1 年**。遇到这种情形，不要硬套 E3，按 §5 降级：
  输出「**费用不可精确复算**」并把合同约定的「次月划出、确认为应支付」写在旁边。
